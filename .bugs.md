# Bugs

## [Fixed] Solar Sails not recognized by Radial Chassis
**Date:** 2026-02-04
**Status:** Fixed

### Description
The user reported that `SolarSailBlock` items were not automatically recognized by the **Radial Chassis** when placed adjacent to it. Unlike standard Create sails, they required **Super Glue** to attach.
If not glued, the chassis would not include them in the contraption assembly, leading to "Not enough sail-like blocks" errors or the bearing spinning without the sails.

### Cause
1.  **Missing Item Tag**: The `SolarSailBlock`s were missing the `create:windmill_sails` **item tag**. The Radial Chassis (and other components) use this tag to identify valid sails.
2.  **Missing Connection Logic**: The Create mod's internal contraption logic (`BlockMovementChecksImpl`) has a hardcoded check for `instanceof SailBlock` to allow automatic attachment (without glue) on the "frame" side. Since `SolarSailBlock` extends `WrenchableDirectionalBlock` and not `SailBlock`, this check failed.

### Fix
1.  **Added Item Tag**: Created `src/main/resources/data/create/tags/item/windmill_sails.json` including all color variants.
2.  **Registered AttachedCheck**: Added a custom `AttachedCheck` in `CreatePhotomovement.java`. This check mimics the `SailBlock` behavior, allowing `SolarSailBlock` to return `CheckResult.SUCCESS` when checking attachment towards the chassis, verifying that the connection axis is perpendicular to the sail's facing.

### Files Modified
- `src/main/resources/data/create/tags/item/windmill_sails.json` (New)
- `src/main/java/com/createphotomovement/CreatePhotomovement.java` (Modified)
