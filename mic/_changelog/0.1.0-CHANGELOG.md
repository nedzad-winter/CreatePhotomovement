# Changelog

## [0.1.0] - Horizontal Solar Generators & Color Variants

### New Features
*   **Horizontal Solar Generator**: Introduced a new directional solar generator block (`HorizontalSolarGeneratorBlock`) that generates power based on its orientation and time of day.
*   **Color Variants**: Added full 16-color support (White, Orange, Magenta, Light Blue, Yellow, Lime, Pink, Gray, Light Gray, Cyan, Purple, Blue, Brown, Green, Red, Black) for both:
    *   The Standard Solar Generator
    *   The new Horizontal Solar Generator

### Code Changes
*   **Block Logic**: Implemented `HorizontalSolarGeneratorBlockEntity` with specific stress capacity calculations based on facing direction (East/West curves) and obstructions.
*   **Registration**: Updated `AllBlocks` and `AllItems` to register all 32 new block variants (16 standard colors + 16 horizontal colors).

### Assets & Data
*   **Models**: Added blockstates, block models, and item models for all 32 new colored variants.
*   **Recipes**:
    *   Added crafting recipes for the Horizontal Solar Generator.
    *   Added **Dyeing Recipes** to color any Solar Generator.
    *   Added **Conversion Recipes** to switch between Standard and Horizontal variants.
*   **Loot Tables**: Added loot tables for all new blocks.
*   **Tags**: Added `horizontal_solar_generators` tags and updated `mineable/axe` and `mineable/pickaxe` tags.
