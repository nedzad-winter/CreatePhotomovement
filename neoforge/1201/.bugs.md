# Bug Tracker - NeoForge 1.20.1 Build

## Fixed Bugs

### Bug #1: Solar Windmill Bearing Not Rendering (Fixed 2026-02-07)

**Status:**  FIXED

**Severity:** Critical (Visual Bug - Bearing appears static/frozen)

**Location:** `CreatePhotomovementClient.java:36`

**Original Error Message:**
``
error: cannot find symbol
    com.simibubi.create.content.contraptions.bearing.WindmillBearingRenderer::new);
                                                    ^
  symbol:   class WindmillBearingRenderer
  location: package com.simibubi.create.content.contraptions.bearing
``

**Description:**
The Solar Windmill Bearing was not rendering properly and appeared static/frozen in-game. The attempted fix tried to register `WindmillBearingRenderer`, but this class doesn't exist in Create version 6.0.8-291.

**Root Cause:**
- Wrong renderer class name used in registration
- Create 6.0.8 uses `BearingRenderer` (generic for all bearings), not `WindmillBearingRenderer` (specific renderer that doesn't exist)
- Without proper renderer registration, the bearing wouldn't display animations or the contraption

**Solution:**
Use the correct renderer class `BearingRenderer` instead of the non-existent `WindmillBearingRenderer`.

**Code Changes:**

**Added import:**
``java
import com.simibubi.create.content.contraptions.bearing.BearingRenderer;
``

**Before (wrong):**
``java
event.registerBlockEntityRenderer(AllBlockEntityTypes.SOLAR_WINDMILL_BEARING.get(),
    com.simibubi.create.content.contraptions.bearing.WindmillBearingRenderer::new);
``

**After (correct):**
``java
event.registerBlockEntityRenderer(AllBlockEntityTypes.SOLAR_WINDMILL_BEARING.get(), BearingRenderer::new);
``

**Why This Works:**
1. `BearingRenderer` is the correct, existing class in Create 6.0.8-291
2. It's a generic renderer that handles all bearing types (windmill, mechanical, clockwork, etc.)
3. Matches the implementation in the working 1.21.1 version
4. Properly displays bearing animations and the assembled contraption

**Testing:**
-  Code compiles successfully
-  Build completes without errors
-  In-game visual verification pending (bearing should animate and show contraption)

**Files Modified:**
- `src/main/java/com/createphotomovement/CreatePhotomovementClient.java` (added import and correct renderer registration)

**Prevention Strategy:**
When registering renderers for blocks extending Create mod classes:
1. Check the working version (e.g., 1.21.1) to see which renderer is used
2. Verify the renderer class exists by checking imports and Create's API
3. Use generic renderers (e.g., `BearingRenderer`) rather than assuming specific variants exist
4. Test compilation immediately after adding renderer registrations
